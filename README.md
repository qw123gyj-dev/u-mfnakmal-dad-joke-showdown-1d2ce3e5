# Dad Joke Showdown

One dad joke, told straight-faced. `main.ts` writes the joke to `entry.txt`, enforcing the entry gates — non-empty, at most 200 characters, at least one sentence — then reads the file back and verifies the bytes match.

> "I asked my dad for money to buy a calendar. He said, \"Son, your days are numbered.\""

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dad-joke-out node main.ts
```
